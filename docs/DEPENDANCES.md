# Third-party dependencies (`NX_TIERS`)

None of these are stored in the repository. Put them in one folder (default: `tiers/` at the repository root) and
pass it to CMake with `-DNX_TIERS=<folder>`.

| Folder in `NX_TIERS` | What | Version |
|---|---|---|
| `eden/` | [Eden](https://git.eden-emu.dev/eden-emu/eden) source (GPL-3.0-or-later): `video_core`, `shader_recompiler`, nvdrv devices | commit `d8c6c59b679867d2595fdc0953df033475e23380`, then `git apply eden_gpu/eden.patch` (see `eden_gpu/CORRECTIFS_EDEN.md`) |
| `eden_gen/include/` | Eden's internal shaders compiled to SPIR-V headers | generated by `python tools/eden/gen_shaders.py` |
| `sirit-1.0.5/` | SPIR-V emitter used by Eden | 1.0.5 |
| `SPIRV-Headers-main/` | Khronos SPIR-V headers | `main` |
| `fmt-12.1.0/` | fmt (header only) | 12.1.0 |
| `boost_1_86_0/` | Boost (headers) | 1.86.0 |
| `dl_vma/VulkanMemoryAllocator-3.3.0/` | Vulkan Memory Allocator | 3.3.0 |
| `dl_xbyak/xbyak-7.40.1/` | xbyak | 7.40.1 |
| `dl_vkutil/Vulkan-Utility-Libraries-1.4.345/` | Vulkan Utility Libraries | 1.4.345 |
| `Vulkan-Headers-1.4.350/` | Vulkan headers | 1.4.350 |
| `SDL3-3.4.18/` | SDL3, Visual C++ development package (`include/`, `lib/x64/`) | 3.4.18 |

Tools:

- LLVM/clang for Windows (`clang.exe`, `clang++.exe`, lld; tested with 23.1.3) and the Visual Studio build tools
  (Windows SDK, `vcvars64.bat`).
- CMake 3.25+, Ninja.
- `glslangValidator` in `PATH`.
- Python 3.10+ with `lz4`, `capstone`, `pyelftools` (`unicorn` for `tools/recomp/test_diff.py`).
- `hactool` and your own console keys, to extract your own game and system data.
